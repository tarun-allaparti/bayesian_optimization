**# Bayesian Optimization

In many optimization problems, finding the best solution can be time-consuming and expensive. **Bayesian optimization (BO)** can be used to optimize the search space, builds a probabilistic model of your objective and uses it to pick the **most informative next experiment**, balancing exploration vs. exploitation. I’ve used BO on real projects with strong results; I've been making a demo to simply understand the tool and more recently visualize it.

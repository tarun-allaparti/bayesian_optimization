# Bayesian Optimization Demo

This repository provides a hands-on demonstration of **Bayesian Optimization (BO)**, a powerful technique for optimizing expensive, black-box functions. BO builds a probabilistic model of your objective function to intelligently select the next experiment, balancing **exploration** and **exploitation**.

The goal of this project is to **understand and visualize Bayesian Optimization** through interactive examples.

## Features

* **Jupyter Notebook Workflow:** Step through the BO process in a detailed notebook, exploring surrogate models, acquisition functions, and iterative optimization.
* **Interactive Streamlit App:** Experiment with different objective functions, visualize the optimization surface, and see Bayesian Optimization in action in real-time.

Getting Started

To explore the interactive Streamlit app, run:

streamlit run app.py
